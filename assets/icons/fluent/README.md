# Fluent System Icons

Selected 20px regular SVG icons from Microsoft Fluent System Icons, downloaded 2026-10-28.
Source: https://github.com/microsoft/fluentui-system-icons/tree/main/assets
License: MIT, reproduced in LICENSE. The text_color and highlight SVGs add a named fill path inside the existing color bar/pen tip; their original Fluent outlines are retained. Other SVGs are unmodified. UiIcons recolors rendered assets with the current UI text/accent token; no icon font is distributed.
The two indicator fills are substituted at runtime; the base glyph follows the application theme and the fill follows the chosen formatting color. The original MIT attribution applies to these derivatives.
